The model asks one question: will the close be above or below the dashed line? The two shaded regions are its answer — each side's depth of colour is that side's probability, so a confident call makes one region clearly dominant. The dashed line stays flat because no price movement is predicted, and the band's height is recent realised volatility, used only to give the probabilities a realistic vertical scale. No price, expected return or target is produced, and the band must not be read as a predicted price range. Regions are grey whenever the reliability gate has not qualified the direction.

About the framework

CryptoLens combines saved forecasting models, live outcome monitoring, and reviewed news context. The Research, Review, and Decision agents use the OpenAI Agents SDK to prepare answers from application data and retrieved sources.

Forecasts are recorded before outcomes are scored. Directional probability and validated reliability are shown separately. News provides context and does not increase a model's measured reliability.

Thesis prototype

This application explores how market data and news context can support cryptocurrency forecasting research. Bitcoin, Ethereum and Cardano are all within the study's scope, and each is selectable above.

Only Bitcoin currently has trained artifacts, deployed across the 1h, 6h and 24h horizons. Ethereum and Cardano are declared in the asset catalogue but report no model, so the interface withholds a forecast for them rather than estimating one or reusing Bitcoin's. Each needs its own market history and training run; because the sentiment corpus is Bitcoin-specific, their first models would be market-only.
